# Nikotama-WebGL

## Node.js

このプロジェクトは、以下のバージョンで動作を確認しています。

- Node.js v19.7.0

Node.jsがインストールされているか分からない場合は、ターミナルで次のコマンドを実行してください。

```bash
node --version
```

バージョン番号が表示されれば、Node.jsはインストールされています。

## セットアップ

### 1. 必要なパッケージをインストールする

このプロジェクトのフォルダーをVS Codeで開き、ターミナルで次のコマンドを実行します。

```bash
npm install
```

この操作は初回、または使用するパッケージが変更されたときに必要です。

### 2. 開発用サーバーを起動する

インストールが完了したら、次のコマンドを実行します。

```bash
npm run dev
```

ターミナルに表示されたURL（通常は `http://localhost:5173/`）をWebブラウザーで開くと、作品を確認できます。

サーバーを終了するには、コマンドを実行しているターミナルで <kbd>Control</kbd> + <kbd>C</kbd> を押します。

## URLクエリ仕様

URLの末尾に「クエリパラメーター」を追加すると、表示するバージョンや表示方法を指定できます。

たとえば、次のURLでは `cubeType=type1` がクエリパラメーターです。

```text
http://localhost:5173/?cubeType=type1
```

クエリパラメーターを指定しなくても作品は表示できます。その場合は、各項目のデフォルト値が使用されます。

> [!IMPORTANT]
> パラメーター名と値は、大文字と小文字を区別します。表に記載されたとおりに入力してください。

### バージョン

`cubeType`を使って、キューブのレイアウトを選択します。

| バージョン | クエリ | ローカルURL |
| --- | --- | --- |
| タイプ1 | `cubeType=type1` | `http://localhost:5173/?cubeType=type1` |
| タイプ2（デフォルト） | `cubeType=type2` | `http://localhost:5173/?cubeType=type2` |
| タイプ3 | `cubeType=type3` | `http://localhost:5173/?cubeType=type3` |

### パラメーター

すべてのパラメーターを指定する必要はありません。変更したい項目だけをURLに追加できます。

| パラメーター | 使用可能な値 | デフォルト | 説明 |
| --- | --- | --- | --- |
| `cubeType` | `type1`、`type2`、`type3` | `type2` | キューブのレイアウト／バージョンを選択します。 |
| `debug` | `true`、`1`、`false`など | `false` | デフォルトでは各面を合成した完成形を表示します。`debug=true`でキューブの各面を確認するデバッグ表示に切り替えます。 |
| `debugProjection` | `true`、`1`、`false`など | `false` | キューブの各面にマッピングする前のプロジェクター映像を、768×768の平面で表示します。キャンバスサイズが上書きされます。 |
| `debugImage` | `true`、`1`、`false`など | `false` | 選択中の`cubeType`に対応する多摩川のライブカメラ映像と、その代表色を下部に表示します。キャンバスサイズが上書きされます。 |
| `lilGUI` | `true`、`1`、`false`など | `false` | lil-guiのコントロールパネル（代表色のしきい値を含む）を表示します。 |

### 参照カメラ

`debugImage`は、各キューブが参照する場所に最も近いライブカメラを表示します。
映像は国土交通省「川の防災情報」のものです。URLは`src/modules/Artwork.ts`にあります。

| キューブ | カメラ |
| --- | --- |
| `type1` | 多摩川二子玉川ライズタワーオフィス屋上 |
| `type2` | 多摩川二子橋 |
| `type3` | 多摩川田園調布出張所 |

映像の下には、代表色が最大5つ円で表示されます。50×50に収まるよう縮小した映像の
ピクセルのうち、HSBの彩度と明度がしきい値を超えるものを対象に、RGB空間で最も
離れた色を順に選び（`src/modules/keyColors.ts`）、輝度の低い順に並べます。

### カメラ連動のグラデーション

この代表色は、`debugImage`のときだけでなく、すべての表示でグラデーションとして
使用されます。映像は起動時に取得され、60秒ごとに更新されるため、時間帯による
川の光の変化がそのまま作品の色になります。最初の映像が届くまでは黒から白の
グラデーションが表示されます。色の変化（初回の取得、更新、しきい値の変更）は
すべて1秒かけてクロスフェードします。

色はシェーダーのグラデーション段数に合わせて再配置されます。条件を満たす色が
2つ未満の場合（曇天時によく起こります）は、赤・緑・青にフォールバックします。
しきい値は`minSaturation`と`minBrightness`で、既定値はどちらも0.1です。
lil-guiパネル（`lilGUI=true`）の**Key Colours**から、表示中に変更できます。

本作は実行のたびに`cam.river.go.jp`へアクセスするため、ネットワーク接続が必要で、
公開した場合は第三者のライブ映像を直接参照することになります。

配信元は`Access-Control-Allow-Origin: *`を返すため、ブラウザーからテクスチャーとして
利用できます。ただし、ブラウザー以外のUser-Agentからのアクセスは拒否されます。
`curl`やスクリプトで取得すると403になります。

### `debug`クエリについて

`debug`は、制作・調整用の表示と完成形の表示を切り替えるためのパラメーターです。

#### デバッグ表示を使う

`debug=true`または`debug=1`を指定すると、デバッグ表示になります。

- キューブの各面を分離して表示します。
- 各面の位置や模様を確認しやすい表示です。
- 描画にはデバッグ用カメラを使用します。
- `debug`をURLに指定しなかった場合も、この表示になります。

```text
http://localhost:5173/?debug=true
```

#### 完成形を表示する

`debug=false`を指定すると、各面を1つに合成した完成形を表示します。

- キューブの各面を合成して表示します。
- 実際に公開・鑑賞するときの見え方を確認できます。
- 描画には通常のカメラを使用します。

```text
http://localhost:5173/?debug=false
```

> [!NOTE]
> `true`または`1`以外の値を指定すると、デバッグ表示は無効になります。意図が伝わりやすいように、完成形を表示するときは`debug=false`を使用してください。

### 複数のパラメーターを指定する

最初のパラメーターはURLの後ろに`?`を付けて記述します。2つ目以降は`&`でつなぎます。

たとえば、次の設定を使用する場合を考えます。

- レイアウト：タイプ3
- 表示：キューブ面を合成した完成形

URLは次のようになります。

```text
http://localhost:5173/?cubeType=type3&debug=false
```

### 簡単な使用例

| やりたいこと | URL |
| --- | --- |
| デフォルト設定で表示する | `http://localhost:5173/` |
| タイプ1を表示する | `http://localhost:5173/?cubeType=type1` |
| タイプ2の完成形を表示する | `http://localhost:5173/?cubeType=type2&debug=false` |

公開された環境でも、サイトのURLの後ろに同じ形式のクエリパラメーターを追加できます。

表に記載されていない値を指定した場合の動作は保証されません。
